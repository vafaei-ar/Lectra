Good afternoon everyone.

Today I want to focus on a simple but important question: does a model that performs well in one health system continue to work somewhere else?

<!-- pause: medium -->

Internal validation tells us whether the model can reproduce patterns in data that resemble its development environment. That is useful, but it is not enough.

<!-- slide: 2 -->
<!-- tone: serious -->

External validation is where we begin to test generalizability.

When performance changes substantially across sites, we need to understand whether the problem comes from the population, clinical workflow, measurement, or the model itself.

<!-- pause: short -->
<!-- tone: explanatory -->

This is why site-level validation should be treated as part of the scientific question rather than only as a final technical check.
